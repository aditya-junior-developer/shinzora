Infrastructure

Serious foundations under a calm interface

Built on Postgres, Supabase Auth, server-side Edge Functions and a real deployment pipeline — the parts that decide whether a business platform can be trusted.

AI with a server boundary

Gemini runs only inside an Edge Function. The key never reaches the browser, and every response is validated and rate-limited per plan.

Row-level security by default

Every table is protected by policies: you read and write your own records, administrators act through server-verified roles, nobody escalates themselves.

Domains and subdomains

Search real availability through a registrar provider when connected, compare extensions and track the order. Until then, Shinzora subdomains are available on every plan.

GitHub and Vercel pipeline

Connect an account, create a repository, push generated files and deploy — with deployment status read back from the provider, never assumed.

Payments that wait for proof

UPI QR collection with manual verification today, Razorpay-ready architecture for later. Closing a window never marks anything paid.

Notifications in real time

Generation, deployment, domain and payment events land in a notification centre streamed over Supabase Realtime, with announcements from Shinzora.

Installable workspace

Shinzora is a PWA: install it to your home screen or desktop and it opens like an app, with an offline fallback page instead of a browser error.

Roles and plan limits

Subscription limits for projects, domains and AI usage are enforced in the database and the AI proxy, so entitlements cannot be edited from the client.

How a request actually moves

You submit it with your project attached; it enters a queue an administrator reviews. You are notified when it is approved, when work starts and when it is delivered. Nothing is marked complete by a timer.

Describe what you need →

Service fees are separate from your subscription and are never charged automatically. You receive an amount and a UPI QR, pay it yourself, and the request moves forward only after the payment is verified by a person.

What we will and will not do

No borrowed credibility

You will not find invented customer quotes or made-up metrics on this page. Every statement below is a property of the product you can check yourself, in your own account, after signing up.

Your numbers are yours

Every count on your dashboard is read from your own database rows. A new account shows empty states, not impressive-looking sample data.

Payments stay pending until proven

A UPI payment is recorded as awaiting verification until it is confirmed by a provider webhook or approved by an administrator. Closing a window changes nothing.

Keys live on the server

The AI key, payment secret and provider tokens exist only as Supabase Edge Function secrets. The browser is given a publishable key and nothing else.

Check the wiring yourself

The public system check page probes the live database, storage buckets and functions and reports exactly what is and is not configured.
