Setup guide

Install Shinzora on your device

Shinzora runs as an installed application on every major platform. On phones and desktops alike it installs from your browser: the same workspace, the same account, its own icon and window — and the shell still opens when the connection drops. Pick your platform below.

Why browser installation? A browser-installed app updates instantly, works offline through a service worker, and needs no installer file or app-store account. If a native package is published for your platform, it appears on the Get App screen instead — this guide covers both routes.

Android

Chrome, Edge, Samsung Internet and Brave all install Shinzora as an app.

  1. Open Shinzora in Chrome. Any Chromium browser on Android 8 or newer works.
  2. Tap the three-dot menu at the top right of the browser.
  3. Choose “Install app”. On older versions it is called “Add to Home screen”.
  4. Confirm. Shinzora gets its own icon on the home screen and opens full screen.
Samsung Internet Tap ☰ → Add page to → Home screen. Firefox for Android installs through ⋮ → Install on Android 10+.
APK downloads If a signed APK is published, it appears as a download button on the Get App screen. Nothing is linked here that does not exist — sideloading is never required to use Shinzora.

iPhone & iPad

Safari is the supported route on iOS and iPadOS — Chrome and Firefox cannot add to the Home Screen.

  1. Open Shinzora in Safari.
  2. Tap the Share button in the toolbar — the square with an arrow pointing up.
  3. Scroll and choose “Add to Home Screen”.
  4. Name it and tap “Add”. The icon appears on your Home Screen and launches full screen.
On iPadOS The Share button sits next to the address bar. The rest of the flow is identical.
No IPA is published Shinzora is not distributed through the App Store, so there is no IPA to download. The Home Screen install gives you the same app: same account, same offline shell, same notifications where iOS allows them.

Windows

Windows 10 and 11 install the app from Chrome or Edge in a few seconds.

  1. Open Shinzora in Chrome or Edge.
  2. Look at the address bar for the install icon — a monitor with a small arrow.
  3. Click it and confirm. In Edge the menu path is ⋯ → Apps → Install this site as an app.
  4. Launch it from the Start menu. Shinzora opens in its own window, with its own taskbar icon.
Silent install path Chrome also accepts chrome://apps → Shinzora when the icon is not visible in the bar.
EXE / MSI A packaged installer is listed on the Get App screen only once it has been built and uploaded. Until then the browser install is the supported route, and it is not a cut-down version: it is the same application.

macOS

Chrome and Edge install a proper app; Safari 14+ can add Shinzora to the Dock.

  1. Chrome or Edge: click the install icon at the right of the address bar, then Install.
  2. Safari 14 or newer: choose File → Add to Dock.
  3. Launch from Launchpad (or the Dock). Shinzora runs in its own window with its own icon.
  4. Sign in once. The session persists, and the shell opens when you are offline.
DMG A signed .dmg is offered only when one has been notarised and uploaded. macOS Gatekeeper would reject an unsigned build anyway, so the browser route stays the default.

Linux

Chrome and Chromium install Shinzora as a desktop application on every major distribution.

  1. Open Shinzora in Chrome or Chromium.
  2. Use the install icon in the address bar, or the ⋮ menu → Cast, save and share → Install.
  3. Confirm. A launcher is written to your application menu.
  4. Launch it like any other app — KDE, GNOME and XFCE all pick it up.
AppImage / DEB / RPM Distribution packages are listed on the Get App screen when they exist. They are never generated on the fly and never linked to a placeholder file.

If the install option does not appear

Four causes, in order of likelihood.

  • The page is already installed. Open it from your home screen or Start menu instead.
  • The browser does not support installation. Use Chrome, Edge, Samsung Internet, or Safari on iOS/macOS. Firefox desktop and in-app browsers (Instagram, LinkedIn, Gmail) cannot install web apps.
  • The connection is not secure. Installation requires HTTPS. localhost is the only exception.
  • The service worker is stale. Reload once, or clear the site data, then try again.

Still stuck? Write to official.shinzora@proton.me with your platform and browser version — the same workspace works in a normal browser tab in the meantime, so nothing is blocked.
