Get Shinzora

One platform, several ways in. The browser platform is live and complete today. The Windows desktop application ships from this repository as a real installer. Every other platform says exactly what it is: coming soon, until the package exists.

Installing the website from your browser is not the desktop application. A progressive-web-app install adds an icon and a full-screen window, but it is still the browser. The Windows entry below is a separate native package with its own installer, shortcut and uninstaller.

Windows

Source build ready

Electron application window with the official Shinzora icon, Start Menu and desktop shortcuts, and an NSIS uninstaller. The installer has not been built yet — build it on Windows, where it can also be installed and tested, with the commands below.

.EXE (NSIS)x64
cd desktop npm install npm run dist:win → release/Shinzora-Setup-1.0.0.exe

Until that file exists, there is no download button here — a button that downloads nothing would be a lie.
